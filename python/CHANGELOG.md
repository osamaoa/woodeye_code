# Changelog

## 1.0.0

- Added the initial Python package for optical-to-CT landmark alignment.
- Added core transform fitting, RANSAC, warping, coverage, patch export, JSON schemas, project I/O, batch processing, and report generation.
- Added a PyQt6/pyqtgraph GUI shell for loading images, placing control point pairs, fitting transforms, verifying overlays, and generating patches.
- Added unit and smoke tests plus user/developer documentation.
